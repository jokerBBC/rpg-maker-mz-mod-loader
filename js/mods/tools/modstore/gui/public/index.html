Mod 商店打包工具

标准 zip 打包 · 版本比对 · 可选推送 Gitee / GitHub

请先在设置中配置 _localmods 路径。zip 文件名 = 包目录名 + 版本，多脚本包须在 modloader.json 写 version。

尚未扫描
请先在设置中填写 _localmods，再点击「扫描 Mod」

未填输出目录时，zip / catalog / git 仓库默认在 gui/user-data/repo-cache/。生成 catalog 只需仓库地址；推送与拉取需令牌。

远程 Git 仓库（进阶）

        
令牌与发布记录保存在 gui/user-data/。生成 catalog 只需仓库地址；推送与拉取需令牌。

        
        
        
        
        
        

          其他 Git 平台 raw 地址（可选）
          
用于非 Gitee / GitHub，或需自定义 Git raw 路径时。生成 catalog 时写入 downloadUrl；留空则由 Gitee/GitHub 地址自动拼接。

          
          
占位符：{owner} {repo} {branch} {subdir} {file} {host}

        

      


      

        
静态分发渠道（可选）

        
zip 由自建 CDN、对象存储、网盘直链等静态站点分发（不经过 Git raw）时填写。填写后 catalog 的 downloadUrl 优先使用此模板；你仍需自行上传 zip 到对应位置。

        
        
占位符：{file} 为 zip 文件名；可选 {branch} {subdir}
